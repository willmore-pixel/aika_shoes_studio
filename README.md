# Aika Shoes Studio

鞋子配色網站 AIKA PLAY：https://willmore-pixel.github.io/aika_shoes_studio/play/ （另有 /app/ 同一頁）。

- 網站本體是 `play/index.html`，推上 main 後會自動發布；鞋款讀取 aika_swatches 的 styles.json。
- 舊的線稿版首頁（根目錄 `index.html`）已於 2026-10-28 關閉，根網址現在是 404；舊版留在 git 歷史裡。
- **色卡照片不放在這裡**，放在 [aika_swatches](https://github.com/willmore-pixel/aika_swatches)。網站每次打開都會讀取那邊最新的色卡。
